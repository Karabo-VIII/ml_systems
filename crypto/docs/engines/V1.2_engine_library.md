covering catalog **Family 1 (Trend)**, **Family 2 (Momentum / Oscillator)**, **Family 3 (Volatility)**.

**Protocol (every engine identical):** `src/strat/deep2020_ti_pipeline.py` -- 2020 band, fixed-EW
**long-only spot**, VAL Jul-Sep **select** / OOS Oct-Dec **report**, maker cost, **rank by net WEALTH**.
Each engine = a base signal + a family-validated IRON (trend/momentum -> uptrend `c>SMA100`; breakout ->
ATR-confirm; MR osc -> buy-dip-in-uptrend; volatility -> regime/squeeze gate) + trail-stop + min-hold +
vol-target overlay. **(CORRECTED)** The **best ironed config** is robust-preferred (`|OOS-VAL|<=10`), then
**max VAL net** (NOT OOS net -- the leak), chosen across all 6 TFs {1d,4h,2h,1h,30m,15m}; that config's OOS
is then reported. **robust-frac** = robust ironed configs / total ironed configs swept across all TFs.
**net xBH** uses the same-cadence buy-hold on the 27-name universe (see each engine's `buyhold_net`).
